설정

Sentory의 실행, 메신저 감지와 보관 데이터를 한곳에서 관리합니다

일반

화면 테마라이트 모드와 다크 모드를 선택합니다
Language화면에 표시할 언어를 선택합니다
Windows 시작 시 실행현재 자동 실행을 사용하지 않습니다

메신저 감지

컴퓨터 · 모바일 간 동기화

클라우드 · NAS 공유사진과 링크를 다른 기기에서 바로 보고 공유할 수 있게 동기화합니다 동기화 꺼짐

OneDrive, Google Drive, Dropbox, MEGA 또는 직접 고른 폴더를 사용합니다

NAS의 WebDAV 공유 폴더 주소와 계정을 입력합니다

비밀번호는 Windows 사용자 계정으로 암호화해 저장합니다

데이터 관리

즐겨찾기에 등록된 항목은 자동 정리에서 포함되지 않음
