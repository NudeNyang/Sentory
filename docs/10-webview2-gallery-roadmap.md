# WebView2 갤러리 전환 기록

결정일: 2026-07-28

종료일: 2026-07-29

카드 스크롤 영역만 WPF WebView2 컨트롤로 교체하려던 계획은 종료했다. 관련
개발자판 코드, 환경 변수, 패키지와 배포 라이선스는 제거했고 WPF 앱은 공개판과
같은 1.5.0 전용 렌더러로 복원했다.

이 실험에서 브라우저 가상 스크롤의 가능성은 확인했지만, WPF와 WebView2를 한 창에
함께 유지하면 기본 메모리와 구현 복잡도가 커졌다. 앞으로는 화면 전체를 Tauri UI로
옮기고 메신저 감지·SQLite·OCR·동기화는 C# 엔진에 남긴다. WPF 1.5.0은 기능과
성능의 기준판으로만 유지한다.

현재 방향과 단계별 완료 기준은
[Tauri UI 전환 로드맵](./11-tauri-ui-migration-roadmap.md)을 따른다.
