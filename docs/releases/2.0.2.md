# Sentory 2.0.2

2.0.2에서는 새로 설치했을 때 감지할 메신저를 직접 고르게 했습니다. Discord를
처음 켜는 경우에는 자동 재시작 동작을 먼저 설명하고 동의를 받습니다. 업데이트로
설치한 사용자의 기존 설정과 보관함은 그대로 유지됩니다.

## 처음 실행할 때

- Discord, KakaoTalk, Slack, WhatsApp, Telegram, LINE, WeChat 감지는 모두
  꺼진 상태로 시작합니다. 첫 화면에서 필요한 메신저만 켜거나 `모두 켜기`를
  누르면 됩니다.
- 기존에 Sentory를 쓰던 사용자는 저장된 감지 설정을 그대로 이어받습니다. 초기
  선택 화면도 다시 나오지 않습니다.
- 아무 메신저도 고르지 않았다면 보관함에 설정 바로가기가 남습니다. 나중에
  설정에서 언제든 바꿀 수 있습니다.

## Discord 자동 재시작 동의

Discord 감지를 처음 켤 때 자동 재시작을 허용할지 묻습니다. `모두 켜기`로
Discord가 포함될 때도 같은 안내가 나옵니다. 안내문에는 "작성 중인 메시지가
취소되거나 통화가 종료될 수 있습니다."라고 적었습니다.

동의하지 않으면 Discord 감지는 꺼진 채로 남습니다. 첫 화면을 그대로 마쳤다면
나중에 설정에서 Discord를 켤 때 다시 묻습니다. 동의 기록은 감지 설정이 실제로
켜진 뒤에만 저장합니다. 이미 Discord 감지를 사용하던 사람에게는 다시 묻지
않습니다.

접근성 실행 옵션 없이 열린 Discord는 15초 안내 뒤 자동으로 다시 시작합니다.
안내창에서 바로 재시작하거나 취소할 수 있습니다. 일반적인 연결 준비나 워커 복구
상태에서는 자동으로 종료하지 않습니다.

## 함께 고친 부분

- 메신저 감지 토글을 빠르게 바꿀 때 늦게 도착한 저장 응답이 마지막 선택을
  되돌리던 문제를 고쳤습니다.
- Microsoft Store 제출용 x64·ARM64 MSIX 번들 제작 경로를 추가했습니다.
  GitHub Release에서는 설치형과 포터블을 계속 함께 제공합니다.

| 사용 환경 | 설치형 | 포터블 |
| --- | --- | --- |
| Intel·AMD Windows PC | `Sentory-win-x64-setup.exe` | `Sentory-win-x64-portable.zip` |
| Windows on ARM PC | `Sentory-win-arm64-setup.exe` | `Sentory-win-arm64-portable.zip` |

현재 실행 파일과 설치 프로그램에는 코드 서명이 없습니다. Windows에서 알 수 없는
게시자 또는 SmartScreen 경고가 나타날 수 있으니 공식 Release에서 받은 파일인지
확인해 주세요. 필요하면 함께 올린 `.sha256` 파일과 대조할 수 있습니다. 이 버전의
소스는 `Sentory-2.0.2-source.zip`과 `v2.0.2` 태그에서 받을 수 있습니다.

## English

Sentory 2.0.2 lets new users choose which messengers to monitor during first-run setup.
All seven detection switches start off. Existing installations keep their saved
choices and do not see the setup screen again.

The first time Discord detection is enabled, Sentory asks for consent before allowing
automatic restarts. The dialog warns that a draft message may be cancelled or a call
may end. Declining leaves Discord detection off, so the prompt appears again if it is
enabled later. Consent is remembered only after the enabled setting is saved. Existing
Discord detection users are not asked again.

A Discord process without the required accessibility argument may restart after a
15-second notice. Ordinary connection and worker recovery states do not trigger an
automatic restart. This release also fixes messenger switches being reverted by an
older settings response.

The GitHub Release includes x64 and ARM64 installers and portable packages. The
binaries are not code-signed, so Windows may show an Unknown Publisher or SmartScreen
warning. Verify downloads against the accompanying SHA-256 files when needed.
