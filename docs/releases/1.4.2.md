# Sentory 1.4.2

Discord에서 붙여넣은 사진이나 링크를 전송 전에 지우고 다른 항목을 보내도, 지운 내용이 다음 기록에 섞이지 않습니다. 채팅방을 옮긴 직후에도 현재 창의 첨부 상태를 확인하며, 여러 장이나 여러 링크를 실제로 함께 보낸 경우에는 하나의 묶음으로 남깁니다.

외부 링크와 업데이트 파일을 다루는 검사도 강화했습니다. 링크 미리보기는 실제 연결 직전에도 로컬·사설 주소를 차단하고, 사진과 업데이트 다운로드에는 크기 상한을 두어 비정상 입력이 메모리나 디스크를 계속 차지하지 않게 했습니다. 포함된 OCR 모델의 출처와 확인값은 배포 파일과 앱의 라이선스 화면에서 확인할 수 있습니다.

시스템 테마 안내 문구를 바로잡고, 다크 모드에서는 설정 화면의 보조 버튼이 주변 입력창과 더 잘 구분되도록 손봤습니다.
