# Sentory 1.4.2

Sentory 1.4.2는 Discord에서 보내기 전에 지운 사진이나 링크를 다음 기록에서 정확히
제외합니다. 외부 링크, 큰 사진과 업데이트 파일을 다룰 때 필요한 보호 장치도
보강했습니다. 설정 화면의 안내와 버튼 색상을 손보고, 내장 OCR 모델이 어디에서
왔는지 배포 파일과 앱에서 확인할 수 있게 했습니다.

## 지운 사진과 링크 제외

- Discord에 붙여넣은 사진을 보내기 전에 제거했다가 다른 사진을 전송하면, 제거한
  후보는 버리고 실제로 보낸 사진만 저장합니다.
- 채팅방을 막 옮긴 경우에도 현재 Discord 메인 창의 첨부 미리보기와 제거 버튼을
  기준으로 판단합니다. 여러 장을 한꺼번에 보냈다면 기존처럼 하나의 묶음으로
  남깁니다.
- 입력창에서 앞선 URL을 지우고 다른 URL을 전송하면 실제 메시지에 들어간 URL만
  저장합니다. 여러 URL을 함께 보냈다면 빠뜨리지 않고 모두 남깁니다.

## 외부 입력과 다운로드 보호

- 링크 미리보기는 DNS 응답을 검사한 뒤 실제 소켓을 열기 직전에도 공인 IP인지
  다시 확인합니다. 로컬·사설 주소로 이어지는 연결은 이 단계에서 차단합니다.
- 사진 저장 상한은 한 장당 64MB, 한 번에 12장·총 256MB, 6천만 픽셀입니다.
  크기를 미리 아는 파일과 Discord 응답은 메모리를 한 번만 할당해 불필요한 복사를
  줄였습니다.
- 업데이트 주소는 HTTPS만 받습니다. 패키지가 256MB를 넘거나 체크섬 응답이
  8KB를 넘으면 다운로드를 멈춥니다.
- SQLite 네이티브 번들은 SQLite 3.53.3 기반으로 바꿨습니다. 앱과 테스트에서
  보고되던 NuGet High 취약점 경고도 함께 사라졌습니다.

## 설정 화면과 라이선스

- 시스템 테마를 고른 뒤에는 현재 Windows 색상 이름 대신 `시스템 테마 모드`를
  적용했다는 문구가 나옵니다.
- 다크 모드에서는 Windows 자동 실행, 데이터 폴더, 업데이트 확인과 라이선스
  버튼을 주변 입력창보다 밝게 표시합니다.
- PP-OCRv5 모델과 문자 사전은 공식 원본, 고정 리비전과 SHA-256을 출처 문서에
  적었습니다. 배포 파일과 앱의 라이선스 화면에서 GPL, 제3자 고지와 함께 확인할
  수 있습니다.
- 개발자판의 `지금 확인` 버튼은 자동 확인의 6시간 간격을 기다리지 않고 새 버전을
  조회합니다. 확인 중, 최신 상태, 새 버전 준비와 네트워크 실패 결과도 같은
  화면에서 알려 줍니다.

## 다운로드

대부분의 Windows PC에서는 `Sentory-win-x64-setup.exe`를 받으면 됩니다. 설치하지
않고 사용하려면 `Sentory-win-x64-portable.zip`을 완전히 푼 뒤 `Sentory.exe`를
실행해 주세요. Windows on ARM 사용자는 이름에 `arm64`가 포함된 파일을 선택해
주세요.

현재 파일에는 코드 서명이 적용되지 않았습니다. Windows에서 알 수 없는 게시자나
SmartScreen 경고가 나타날 수 있습니다. 공식 Release에서 받은 파일인지
확인하고, 필요하면 함께 제공되는 `.sha256` 파일과 대조해 주세요.

이 Release의 실행 파일에 대응하는 소스는 `Sentory-1.4.2-source.zip`과
`v1.4.2` 태그에서 받을 수 있습니다.

## 알려진 제한 사항

- Discord의 `+` 버튼을 이용한 파일 선택 업로드는 아직 감지를 보장하지 않습니다.
  사진은 채팅 입력창에 Ctrl+V로 붙여넣은 뒤 전송해 주세요.
- Discord 또는 카카오톡의 화면 구조가 바뀌면 감지가 잠시 멈출 수 있습니다.
- ARM64 패키지는 실제 Windows on ARM 장치에서 최종 검수가 남아 있습니다.
- 실행 파일과 설치 프로그램에는 코드 서명이 적용되지 않았습니다.

## English

Sentory 1.4.2 excludes images and links removed before sending from the next Discord
record. It also strengthens safeguards around external links, large images, and update
downloads, improves settings visibility, and documents the origin of the bundled OCR
models.

### Excluding removed images and links

- If a pasted image is removed before another image is sent, only the image that was
  actually sent is saved.
- Sentory checks attachment previews in the current Discord main window after a channel
  change. Multiple images sent together remain one collection.
- If an earlier URL is deleted before another URL is sent, only URLs confirmed in the
  sent message are saved. Multiple URLs sent together are all preserved.

### Safer external input and downloads

- Link previews recheck the resolved address immediately before opening the socket and
  block local or private destinations.
- Image storage is limited to 64MB per image, 12 images and 256MB per batch, and 60
  million pixels. Known-size files and Discord responses avoid an extra memory copy.
- Update URLs must use HTTPS. Downloads stop above 256MB for packages or 8KB for checksum
  responses.
- The SQLite native bundle now uses SQLite 3.53.3, removing the known NuGet High
  vulnerability warning from the app and tests.

### Settings and license information

- System theme confirmation now names the selected mode instead of the current Windows
  color, and secondary buttons are easier to distinguish in dark mode.
- The bundled PP-OCRv5 models and dictionaries now include official sources, pinned
  revisions, and SHA-256 values. The same provenance is available in distributed files
  and the in-app license viewer alongside the GPL and third-party notices.
- Developer builds include a `Check now` button that bypasses the six-hour automatic
  check interval and reports progress, current-version, available-update, and network
  failure states.

### Download

Most Windows PCs should use `Sentory-win-x64-setup.exe`. Use
`Sentory-win-x64-portable.zip` if you prefer not to install the app, or an `arm64`
package on Windows on ARM. The binaries are not code-signed, so Windows may show an
Unknown Publisher or SmartScreen warning. The matching source is available in
`Sentory-1.4.2-source.zip` and from the `v1.4.2` tag.

### Known limitations

- Uploads selected through Discord's `+` button are not guaranteed to be detected. Paste
  images into the chat input with Ctrl+V and send them instead.
- Detection may pause temporarily if Discord or KakaoTalk changes its interface.
- Final testing of the ARM64 package on a physical Windows on ARM device is still pending.
- The executables and installers are not code-signed.
