# Sentory 1.1.31

Sentory 1.1.31에서는 새 PC에서 Discord 감지가 준비되지 않은 채 멈추는 문제를
바로잡았습니다. 일반 파일을 끌어 보낼 때 전송 화면이 깜빡이던 현상도 함께
고쳤고, 문제 확인에 필요한 로그는 한 파일로 모았습니다.

## Discord 연결과 파일 전송

- 첫 연결 준비를 마치기 전에 Discord가 이미 실행 중이면 재시작 안내가
  나타납니다. 연결 중이거나 워커를 복구하는 동안에는 안내를 유지하고, 감지
  준비가 끝나면 닫습니다.
- 채널을 옮길 때 잠시 메시지 목록을 찾지 못했다는 이유만으로 Discord 재시작을
  요구하지 않습니다.
- PDF나 ZIP처럼 사진이 아닌 파일을 Discord 또는 카카오톡으로 끌어갈 때
  Sentory의 사진 감지 영역이 연달아 나타나지 않습니다. 일반 파일로 확인한
  뒤에는 마우스 버튼을 놓을 때까지 원래 메신저가 드래그를 처리합니다.

## 한 파일로 모은 진단 로그

- 앱과 Discord 접근성 작업자의 기록은
  `%LOCALAPPDATA%\Sentory\logs\sentory.log` 한 파일에 남습니다.
- 이전 버전의 `sentory.previous.log`와 `diagnostics\discord-capture.log`가
  남아 있으면 첫 실행 때 시간순으로 합치고 기존 파일을 정리합니다.
- 로그가 1MB를 넘으면 별도 파일을 만들지 않고 오래된 줄부터 정리합니다.
  URL 원문, 사진 내용, 메시지 본문과 상대 이름은 기록하지 않습니다.

## 테마와 검수판 구분

- 설정의 테마 목록 끝에 시스템 테마를 넣었습니다. 새로 설치했을 때는 이전처럼
  라이트 모드로 시작하며, 시스템 테마를 고르면 실행 중에도 Windows 앱 테마를
  따라갑니다.
- 개발자 검수판은 설정의 버전 문구 옆에 `for Developers`를 표시합니다. 정식
  설치형과 포터블 패키지는 공개판 빌드 검사를 거치며 이 문구가 나타나지
  않습니다.

## 다운로드

대부분의 Windows PC에서는 `Sentory-win-x64-setup.exe`를 받으면 됩니다. 설치하지
않고 사용하려면 `Sentory-win-x64-portable.zip`을 완전히 푼 뒤 `Sentory.exe`를
실행해 주세요. Windows on ARM 사용자는 이름에 `arm64`가 포함된 파일을 선택해
주세요.

현재 파일에는 코드 서명이 적용되지 않았습니다. Windows에서 알 수 없는 게시자나
SmartScreen 경고가 나타날 수 있습니다. 공식 Release에서 받은 파일인지
확인하고, 필요하면 함께 제공되는 `.sha256` 파일과 대조해 주세요.

이 Release의 실행 파일에 대응하는 소스는 `Sentory-1.1.31-source.zip`과
`v1.1.31` 태그에서 받을 수 있습니다.

## 알려진 제한 사항

- Discord의 `+` 버튼을 이용한 파일 선택 업로드는 아직 감지를 보장하지 않습니다.
  사진은 채팅 입력창에 Ctrl+V로 붙여넣은 뒤 전송해 주세요.
- Discord 또는 카카오톡의 화면 구조가 바뀌면 감지가 잠시 멈출 수 있습니다.
- ARM64 패키지는 실제 Windows on ARM 장치에서 최종 검수가 남아 있습니다.
- 실행 파일과 설치 프로그램에는 코드 서명이 적용되지 않았습니다.

## English

Sentory 1.1.31 improves first-time Discord detection, prevents messenger file drags
from flickering, and combines diagnostics into a single log file.

### Discord connection and file drags

- If Discord is already running before first-time detection setup is complete, Sentory
  keeps the restart prompt visible until detection is ready.
- A temporarily unavailable message list during channel navigation is not treated as
  proof that Discord must be restarted.
- Non-image files such as PDFs and ZIP archives pass through the Discord and KakaoTalk
  photo drop overlays without repeated interception.

### One diagnostic log

- App and Discord accessibility-worker diagnostics are written to
  `%LOCALAPPDATA%\Sentory\logs\sentory.log`.
- Older split logs are merged into this file on first launch. When the log grows past
  1 MB, Sentory trims old lines without creating a second file.
- Logs do not include original URLs, photo contents, message bodies, or contact names.

### Theme and build identity

- A system theme option now follows the Windows app theme while Sentory is running.
  Light mode remains the default for new installations.
- Developer builds show `for Developers` beside the version. Public setup and portable
  packages are built separately and do not show this label.

Most Windows PCs should use `Sentory-win-x64-setup.exe`. Use the portable ZIP if you
prefer not to install the app, or an `arm64` package on Windows on ARM. The binaries are
not code-signed, so Windows may show an Unknown Publisher or SmartScreen warning.
