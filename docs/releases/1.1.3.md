# Sentory 1.1.3

Sentory 1.1.3은 항목이 많이 쌓인 보관함의 반응 속도를 다듬고 검수 중 발견한
작은 문제를 고친 버전입니다. 설치 화면은 Sentory의 색과 아이콘에 맞췄습니다.
업데이트 파일은 미리 받아 검증한 뒤 설치 여부를 묻습니다.

## 항목이 많은 보관함

- 화면에 보이는 카드와 위아래 두 줄만 만들고, 나머지는 스크롤할 때 재사용합니다.
- 전체·링크·사진·즐겨찾기 필터와 선택 모드가 바뀔 때 불필요한 전체 갱신을
  줄였습니다.
- 언어를 바꾸면 현재 화면부터 갱신합니다. 화면 밖 카드는 작은 묶음으로 나눠
  처리합니다.

## 사진 저장과 파일 드래그

- 일부 Windows·Discord 조합에서 클립보드 사진의 알파 채널이 모두 0으로 전달돼
  검게 저장되던 문제를 보정했습니다.
- 탐색기에서 사진이 아닌 파일을 다른 앱으로 끌어갈 때 Sentory의 투명 드롭
  영역이 입력을 가로채지 않도록 했습니다.
- 감지 일시정지 때 Discord 후보 취소 때문에 화면이 잠깐 멈추던 작업을
  백그라운드로 옮겼습니다.

## 상세 화면과 설정

- 긴 제목을 드래그할 때 글자 위치를 매번 다시 계산하지 않고 선택 정보를
  재사용합니다.
- 링크와 사진 상세창의 복사 아이콘을 통일하고 즐겨찾기·출처 문구의 위치를
  맞췄습니다.
- Windows 자동 실행 스위치는 화면부터 바꾼 뒤 레지스트리와 설정 파일을
  갱신합니다.
- 다크 모드 메뉴에 남아 있던 불필요한 구분선을 없앴습니다.

## 설치와 업데이트

- 처음 설치할 때 보이는 마법사에 Sentory의 베이지 색상과 아이콘, 고해상도
  전용 그림을 적용했습니다.
- Windows 언어를 자동으로 사용해 별도의 언어 선택창 없이 설치 첫 화면이 열립니다.
- 새 버전 파일을 백그라운드에서 먼저 내려받고 SHA-256 확인을 마친 뒤 설치
  안내를 띄웁니다.
- 이미 받은 파일의 확인값이 맞으면 다시 내려받지 않습니다.
- 설치형 업데이트는 설치 마법사를 다시 보여 주지 않고 적용한 뒤 Sentory를
  다시 엽니다.
- 안내를 닫아도 보관함 위쪽의 수동 설치 버튼으로 다시 진행할 수 있습니다.

## 다운로드

대부분의 Windows PC에서는 `Sentory-win-x64-setup.exe`를 받으면 됩니다. 설치하지
않고 사용하려면 `Sentory-win-x64-portable.zip`을 완전히 푼 뒤 `Sentory.exe`를
실행해 주세요. Windows on ARM 사용자는 이름에 `arm64`가 포함된 파일을 선택해
주세요.

현재 파일에는 코드 서명이 적용되지 않았습니다. Windows에서 알 수 없는 게시자나
SmartScreen 경고가 나타날 수 있습니다. 공식 Release에서 받은 파일인지
확인하고, 필요하면 함께 제공되는 `.sha256` 파일과 대조해 주세요.

이 Release의 실행 파일에 대응하는 소스는 `Sentory-1.1.3-source.zip`과
`v1.1.3` 태그에서 받을 수 있습니다.

## 알려진 제한 사항

- Discord의 `+` 버튼을 이용한 파일 선택 업로드는 아직 감지를 보장하지 않습니다.
  사진은 채팅 입력창에 Ctrl+V로 붙여넣은 뒤 전송해 주세요.
- Discord 또는 카카오톡의 화면 구조가 바뀌면 감지가 잠시 멈출 수 있습니다.
- ARM64 패키지는 실제 Windows on ARM 장치에서 최종 검수가 남아 있습니다.
- 실행 파일과 설치 프로그램에는 코드 서명이 적용되지 않았습니다.

## English

Sentory 1.1.3 improves library performance with large collections and fixes several
issues found during QA. The first-install wizard now uses Sentory artwork and colors.
Updates are downloaded and verified before the install prompt appears.

### Large libraries

- The library creates only visible cards and two buffered rows, then reuses those card
  containers while scrolling.
- Filter, selection, and language changes avoid unnecessary full-library refreshes.
- Visible cards update first after a language change, while off-screen cards are
  processed in small batches.

### Photos, details, and settings

- Clipboard images with an all-zero alpha channel are repaired instead of being saved
  as black images.
- Non-image file drags pass through Sentory's messenger drop overlays.
- Long text selections reuse character layout data, and detail-window icons and labels
  have been aligned.
- Start with Windows updates its control immediately, then saves the registry and
  settings changes in the background.

### Installation and updates

- The first-install wizard uses Sentory colors, icons, and high-resolution artwork.
- The setup language follows Windows without showing a separate language dialog.
- Update packages download and pass SHA-256 verification before the prompt appears.
- A verified cached package is reused instead of being downloaded again.
- Installed copies update without reopening the wizard and start Sentory again when the
  update is complete. The manual install button remains available if the first prompt is
  closed.

Most Windows PCs should use `Sentory-win-x64-setup.exe`. Use the portable ZIP if you
prefer not to install the app, or an `arm64` package on Windows on ARM. The binaries are
not code-signed, so Windows may show an Unknown Publisher or SmartScreen warning.
