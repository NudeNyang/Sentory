# Sentory 2.0.4

2.0.4에서는 항목을 얼마나 자주 다시 썼는지 한눈에 알 수 있도록 횟수 기준을
정리했습니다. 중국어와 일본어 화면의 글꼴도 Windows 환경에 맞게 손봤습니다.
업데이트해도 기존 보관함과 설정은 그대로 유지됩니다.

## 재사용 횟수

상세 화면의 `복사 횟수`는 `재사용 횟수`로 바뀝니다. 큰 숫자는 Sentory 안에서
복사한 횟수와 최근 30일 동안 다른 앱에서 같은 항목을 다시 쓴 횟수를 합한
값입니다. 바로 아래에는 `복사 1회 · 외부 재사용 2회`처럼 두 값을 따로
표시합니다.

링크나 사진을 처음 저장한 동작은 외부 재사용으로 세지 않습니다. 저장된 뒤 같은
항목을 다시 붙여넣거나 드롭한 경우부터 올라갑니다. 자동 즐겨찾기도 이 합계를
기준으로 판단하므로, 화면에 보이는 재사용 횟수와 즐겨찾기 등록 기준이 같습니다.
설정에 적힌 기준 횟수와 기존 설정값은 달라지지 않습니다.

## 다국어 글꼴

일본어 화면은 Yu Gothic UI, 중국어 화면은 Microsoft YaHei UI를 우선 사용합니다.
한 화면에서 라틴 문자와 CJK 문자의 굵기가 들쭉날쭉해 보이던 부분을 정리했고,
중국어 제목과 선택 항목은 지나치게 두껍지 않도록 강조 굵기를 낮췄습니다.

한국어 화면은 기존 글꼴 구성을 유지합니다. 화면 언어를 바꿔도 왼쪽 위의
`Sentory` 제목에는 같은 한국어 글꼴 구성이 적용되어 브랜드 모양이 달라지지
않습니다.

현재 실행 파일과 설치 프로그램에는 코드 서명이 없습니다. Windows에서 알 수 없는
게시자나 SmartScreen 경고가 나타날 수 있습니다. 공식 Release에서 받은 파일인지
확인하고, 필요하면 함께 제공되는 `.sha256` 파일과 비교해 주세요. 이 버전의 소스는
`Sentory-2.0.4-source.zip`과 `v2.0.4` 태그에서 받을 수 있습니다.

## English

Sentory 2.0.4 aligns the usage number shown in item details with the value used for
automatic favorites. It also improves font consistency in the Japanese and Chinese
interfaces. Existing libraries and settings remain unchanged after the update.

The former Copy count field is now Reuse count. Its main value combines copies made
inside Sentory with matching external reuse sessions from the last 30 days. The line
below separates the two values, for example, `1 copy · 2 external reuses`.

The action that first saves a link or image does not count as external reuse. Counting
starts only when the saved item is pasted or dropped again. Automatic favorites use
the same combined value shown in the detail window, while the configured threshold
and existing setting remain unchanged.

Japanese now prefers Yu Gothic UI and Chinese prefers Microsoft YaHei UI. Mixed Latin
and CJK text uses more consistent weights, and emphasized Chinese labels are lighter.
The Korean interface keeps its previous font stack. The Sentory title also keeps the
same Korean font stack when the display language changes.

The GitHub Release includes x64 and ARM64 installers and portable packages. These files
are not code-signed, so Windows may show an Unknown Publisher or SmartScreen warning.
Use the accompanying SHA-256 files to verify downloads when needed.
