# Sentory 2.0.1

2.0.1은 Tauri 전환 뒤 빠진 동작을 보완하는 업데이트입니다. 새 설치의 Discord
감지는 사용자가 직접 켜도록 바꿨고, Tauri에서 멈춰 있던 사진 OCR을 다시
연결했습니다. 기존 보관함과 설정은 그대로 이어집니다.

## Discord 시작 방식

- 새로 설치하면 Discord 감지가 꺼진 상태로 시작합니다. 첫 실행에서 이 내용을
  알리고, 필요할 때 설정에서 켤 수 있도록 안내합니다.
- 감지를 켠 뒤 실행 중인 Discord에 접근성 실행 옵션이 실제로 없을 때만 15초
  재시작 안내가 나타납니다. 기다리지 않고 바로 재시작하거나 취소할 수도
  있습니다.
- 일반적인 연결 준비, 일시적인 연결 끊김, 감지 워커 복구만으로 Discord를
  종료하지 않습니다.
- 연결이 끊긴 상태에서 첫 붙여넣기나 드롭을 놓치면 해당 항목이 저장되지 않았다고
  바로 알리고 수동 재시작 버튼을 보여 줍니다.

## 사진 OCR

- WPF 제거 과정에서 빠졌던 OCR 백그라운드 작업자를 Tauri C# 엔진에
  복원했습니다.
- 직접 캡처한 사진뿐 아니라 웹사이트 등에서 복사한 이미지도 지원 메신저에서
  저장되면 같은 OCR 대기열로 처리합니다.
- 단순히 클립보드에 복사했다는 이유만으로 이미지를 읽거나 저장하지 않습니다.
  메신저별 저장 조건을 통과한 사진만 대상이 됩니다.
- OCR은 PC 안에서 처리하며, 결과가 나오면 보관함 제목과 검색 결과에 바로
  반영됩니다. 이전에 처리되지 않은 사진도 앱을 실행하면 차례로 인식합니다.

## 배포판

제품 실행 파일은 Tauri판으로 통일했습니다. 2.0.1은 x64와 ARM64 설치형·포터블을
함께 제공합니다. 개발자판과 정식 배포판의 버전도 모두 2.0.1로 맞췄습니다.

| 사용 환경 | 설치형 | 포터블 |
| --- | --- | --- |
| Intel·AMD Windows PC | `Sentory-win-x64-setup.exe` | `Sentory-win-x64-portable.zip` |
| Windows on ARM PC | `Sentory-win-arm64-setup.exe` | `Sentory-win-arm64-portable.zip` |

- .NET Release 테스트 728개
- Tauri 웹 테스트 45개
- Rust 테스트 6개
- x64 설치 자체 점검
- ARM64 Windows 러너의 네이티브 빌드, PE 아키텍처 확인과 설치 자체 점검

## 알아둘 점

- 실행 파일과 설치 프로그램에는 코드 서명이 적용되지 않았습니다. Windows에서
  알 수 없는 게시자 또는 SmartScreen 경고가 나타날 수 있습니다.
- ARM64 패키지는 ARM64 Windows 환경에서 자체 점검을 마쳤지만, 메신저를 설치한
  실제 Windows on ARM 장치에서의 통합 검수는 남아 있습니다.
- 메신저의 `+` 버튼으로 파일 선택창을 여는 업로드는 감지를 보장하지 않습니다.
  사진은 채팅 입력창에 붙여넣거나 탐색기에서 드롭해 주세요.

배포 파일이 공식 Release에서 받은 것인지 확인하고, 필요하면 함께 제공하는
`.sha256` 파일과 대조해 주세요. 이 버전에 대응하는 소스는
`Sentory-2.0.1-source.zip`과 `v2.0.1` 태그에서 받을 수 있습니다.

## English

Sentory 2.0.1 fills gaps found after the Tauri migration. Discord detection now starts
off on new installations and only offers an automatic restart when the running Discord
process is confirmed to be missing its accessibility launch argument. Ordinary
connection and worker recovery states do not restart Discord.

The image OCR background worker is connected to the Tauri C# engine again. Images
copied from websites are eligible for local OCR after they meet a supported
messenger's save rules. Sentory does not read or save an image merely because it was
copied to the clipboard.

This release includes x64 and ARM64 installers and portable packages. Existing
libraries and settings remain compatible. The release passed 728 .NET tests, 45 web
tests, and 6 Rust tests. ARM64 packages are built and self-checked on a native ARM64
Windows runner.

The binaries are not code-signed. Windows may show an Unknown Publisher or SmartScreen
warning. Physical Windows on ARM messenger integration testing is still pending, and
uploads opened through a messenger's `+` file picker are not guaranteed to be detected.
