# Sentory 1.4.1

Sentory 1.4.1은 Discord가 업데이트나 자체 재실행으로 새 창을 만들었을 때 감지
연결을 다시 찾습니다. Windows 로그인 때 실행 순서가 달라져도 Discord가 감지에
필요한 옵션과 함께 시작되도록 정리했습니다. 아직 채팅방을 열지 않은 정상 대기
상태는 연결 오류로 표시하지 않습니다.

## Discord 재실행 뒤 자동 복구

- Sentory 실행 중 Discord의 접근성 대상이 바뀌면 다음 전송 확인에서 새 창을
  자동으로 탐색합니다.
- 새 창을 찾으면 감지 준비 완료 상태로 돌아갑니다. 계속 찾지 못할 때만 재연결
  안내와 Discord 재시작 버튼을 표시합니다.
- 초기 메시지 목록이 없어도 채팅방을 열지 않은 상태라면 오류로 처리하지
  않습니다. 실제 전송 뒤 복구까지 실패한 경우에만 재연결을 안내합니다.

## Windows 로그인 연결 안정화

Windows 자동 실행과 Discord 감지를 함께 사용하면 Discord가 접근성 옵션을 포함한
명령으로 시작됩니다. 두 프로그램의 실행 순서가 달라져도 감지 준비는 그대로
이어집니다.

기존 Discord 자동 실행 명령은 값 형식까지 따로 보관합니다. Sentory 자동 실행이나
Discord 감지를 끄거나 앱을 제거하면, 사용자가 따로 바꾼 설정은 건드리지 않고
원래 명령으로 돌려놓습니다.

## 다운로드

대부분의 Windows PC에서는 `Sentory-win-x64-setup.exe`를 받으면 됩니다. 설치하지
않고 사용하려면 `Sentory-win-x64-portable.zip`을 완전히 푼 뒤 `Sentory.exe`를
실행해 주세요. Windows on ARM 사용자는 이름에 `arm64`가 포함된 파일을 선택해
주세요.

현재 파일에는 코드 서명이 적용되지 않았습니다. Windows에서 알 수 없는 게시자나
SmartScreen 경고가 나타날 수 있습니다. 공식 Release에서 받은 파일인지
확인하고, 필요하면 함께 제공되는 `.sha256` 파일과 대조해 주세요.

이 Release의 실행 파일에 대응하는 소스는 `Sentory-1.4.1-source.zip`과
`v1.4.1` 태그에서 받을 수 있습니다.

## 알려진 제한 사항

- Discord의 `+` 버튼을 이용한 파일 선택 업로드는 아직 감지를 보장하지 않습니다.
  사진은 채팅 입력창에 Ctrl+V로 붙여넣은 뒤 전송해 주세요.
- Discord 또는 카카오톡의 화면 구조가 바뀌면 감지가 잠시 멈출 수 있습니다.
- ARM64 패키지는 실제 Windows on ARM 장치에서 최종 검수가 남아 있습니다.
- 실행 파일과 설치 프로그램에는 코드 서명이 적용되지 않았습니다.

## English

Sentory 1.4.1 restores Discord detection after an update or self-restart creates a new
window. It also keeps detection ready when Windows starts Sentory and Discord in a
different order. An unopened chat is treated as a normal waiting state, not a
connection error.

### Automatic recovery after Discord restarts

- When Discord replaces its accessibility target, Sentory searches for the new window
  on the next send confirmation.
- Detection returns to Ready after recovery. The reconnect prompt and Discord restart
  button appear only when the new target cannot be found.
- An empty initial message list is not treated as an error until a real send also fails
  to recover the connection.

### Reliable startup at Windows sign-in

When Start with Windows and Discord detection are both enabled, Discord starts with the
required accessibility option regardless of startup order. Sentory preserves the
previous Discord startup command, including its registry value type, and restores it
without overwriting later user changes when the feature is disabled or the app is
removed.

### Download

Most Windows PCs should use `Sentory-win-x64-setup.exe`. Use
`Sentory-win-x64-portable.zip` if you prefer not to install the app, or an `arm64`
package on Windows on ARM. The binaries are not code-signed, so Windows may show an
Unknown Publisher or SmartScreen warning. The matching source is available in
`Sentory-1.4.1-source.zip` and from the `v1.4.1` tag.

### Known limitations

- Uploads selected through Discord's `+` button are not guaranteed to be detected. Paste
  images into the chat input with Ctrl+V and send them instead.
- Detection may pause temporarily if Discord or KakaoTalk changes its interface.
- Final testing of the ARM64 package on a physical Windows on ARM device is still pending.
- The executables and installers are not code-signed.
