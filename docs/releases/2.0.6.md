# Sentory 2.0.6

Sentory 2.0.6은 트레이 메뉴와 보관함에서 눈에 띄던 불편을 다듬고 OCR 결과를 보정한 안정화 업데이트입니다. 새로운 기능을 늘리기보다 실제 사용 중 거슬리던 부분을 정리하는 데 집중했습니다.

## 트레이 메뉴

트레이 메뉴를 여러 번 열고 닫다 보면 드물게 창 전체가 검게 보이던 문제를 고쳤습니다. 메뉴의 여백과 둥근 모서리는 원래 느낌을 살리고, 아래쪽에 남던 불필요한 공간은 없앴습니다.

이제 트레이 아이콘을 왼쪽 버튼으로 누르면 최소화되거나 숨겨진 Sentory 창이 바로 나타납니다. 감지 일시정지, Windows 자동 실행, Discord 자동 연결 설정을 바꿀 때는 메뉴가 그대로 열려 있습니다. 보관함 열기, 데이터 폴더 열기, 종료를 선택했을 때만 닫힙니다.

## 보관함 드래그

빈 공간을 드래그해 여러 카드를 선택할 때 제목, 날짜, 상태 문구가 브라우저 글자처럼 함께 잡히던 문제를 고쳤습니다. 마우스를 놓은 자리에 있던 카드가 뜻하지 않게 열리는 현상도 함께 해결했습니다.

카드 안의 글자를 복사하려고 드래그한 뒤 상세 화면이 열리던 문제도 수정했습니다. 글자 선택과 복사는 그대로 쓸 수 있고, 평소처럼 카드를 누르는 동작도 달라지지 않습니다.

## OCR 결과

사진 속 작은 아이콘이 `ㄷDiscord`처럼 한글 자모로 잘못 읽히는 경우를 보정했습니다. 공백 뒤의 단독 자모가 영문 단어에 바로 붙은 경우만 다루기 때문에 `ㄷㄷ`, `ㄷ 키`, `C#`, `C++` 같은 실제 문구는 그대로 남습니다.

OCR 처리 버전이 바뀌면서 기존 사진도 백그라운드에서 다시 읽습니다. 보관함에 사진이 많다면 반영까지 잠시 걸릴 수 있습니다.

## 그 밖의 변경

Sentory의 기능과 개인정보 처리 방식을 한곳에서 볼 수 있는 소개 페이지를 추가했습니다. 다운로드 버튼은 항상 최신 GitHub Release로 연결되며, README에는 Microsoft Store 후원판 안내를 가볍게 덧붙였습니다.

Microsoft Store판은 Store에서 업데이트합니다. 앱 안의 GitHub 업데이트 메뉴와 확인 경로는 들어가지 않습니다.

2.0.5 GitHub판은 앱 안에서 2.0.6을 확인하고 내려받을 수 있습니다. 현재 실행 파일과 설치 프로그램은 코드 서명을 받지 않아 Windows에서 알 수 없는 게시자 또는 SmartScreen 경고가 나타날 수 있습니다. 공식 Release에서 받은 파일인지 확인하고, 필요하면 함께 제공되는 `.sha256` 파일과 비교해 주세요.

## English

Sentory 2.0.6 is a stability update focused on the tray menu, gallery interactions, and OCR cleanup.

The tray menu no longer depends on transparent WebView composition, fixing an intermittent black background. Its original spacing and rounded shape remain intact, and left-clicking the tray icon restores the main window. Toggle actions keep the menu open, while navigation and exit actions close it.

Gallery drag selection no longer selects card text or opens the card under the pointer. Dragging selectable text inside a card also no longer opens its detail view after release.

OCR post-processing now removes a narrow class of inline icon artifacts misread as a single Hangul jamo before a Latin word. Existing images are reprocessed in the background with the updated OCR revision.

Microsoft Store builds use Store updates and do not expose the in-app GitHub update path. The GitHub Release includes x64 and ARM64 installers and portable packages. These files are not code-signed, so Windows may show an Unknown Publisher or SmartScreen warning.
