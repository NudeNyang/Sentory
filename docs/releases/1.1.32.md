# Sentory 1.1.32

Sentory 1.1.32에서는 업데이트 설치 버튼을 누른 뒤 앱만 닫히고 이전 버전이
그대로 남던 문제를 고쳤습니다. 이제 실행 중인 Sentory가 완전히 종료된 뒤
설치가 시작되며, 진행창을 거쳐 새 버전을 적용한 다음 자동으로 다시 열립니다.

## 보이는 업데이트 과정

- 업데이트 전용 헬퍼가 현재 Sentory의 종료를 확인한 뒤 설치 파일을 실행합니다.
  설치 프로그램이 실행 중인 앱을 먼저 발견해 취소되던 순서 문제를
  바로잡았습니다.
- 설치 마법사 전체를 다시 띄우지 않고 업데이트 진행창만 표시합니다.
- 설치가 끝나면 새 Sentory를 자동으로 엽니다. 설치에 실패하면 기존 실행
  파일을 다시 열고 결과를 `%LOCALAPPDATA%\Sentory\logs\sentory.log`에
  남깁니다.

## 구버전에서 바로 갱신

- 새 설치 프로그램은 실행 중인 Sentory를 발견해도 바로 취소하지 않고 앱이
  종료될 때까지 기다립니다. 업데이트 헬퍼가 없던 1.1.3과 1.1.31에서도
  1.1.32 설치 파일로 바로 갱신할 수 있습니다.
- 배포 전 검증은 Sentory가 실행 중인 상태에서 업데이트를 시작해 진행창 표시,
  파일 교체와 자동 재실행까지 확인합니다.

## 다운로드

대부분의 Windows PC에서는 `Sentory-win-x64-setup.exe`를 받으면 됩니다. 설치하지
않고 사용하려면 `Sentory-win-x64-portable.zip`을 완전히 푼 뒤 `Sentory.exe`를
실행해 주세요. Windows on ARM 사용자는 이름에 `arm64`가 포함된 파일을 선택해
주세요.

현재 파일에는 코드 서명이 적용되지 않았습니다. Windows에서 알 수 없는 게시자나
SmartScreen 경고가 나타날 수 있습니다. 공식 Release에서 받은 파일인지
확인하고, 필요하면 함께 제공되는 `.sha256` 파일과 대조해 주세요.

이 Release의 실행 파일에 대응하는 소스는 `Sentory-1.1.32-source.zip`과
`v1.1.32` 태그에서 받을 수 있습니다.

## 알려진 제한 사항

- Discord의 `+` 버튼을 이용한 파일 선택 업로드는 아직 감지를 보장하지 않습니다.
  사진은 채팅 입력창에 Ctrl+V로 붙여넣은 뒤 전송해 주세요.
- Discord 또는 카카오톡의 화면 구조가 바뀌면 감지가 잠시 멈출 수 있습니다.
- ARM64 패키지는 실제 Windows on ARM 장치에서 최종 검수가 남아 있습니다.
- 실행 파일과 설치 프로그램에는 코드 서명이 적용되지 않았습니다.

## English

Sentory 1.1.32 fixes installed updates that closed Sentory without replacing the
previous version. Updates now show progress, install after the running app exits, and
relaunch Sentory automatically.

### Visible update progress

- A dedicated helper waits for the current Sentory process to exit before launching
  setup, avoiding the single-instance check that previously cancelled installation.
- Updates show a progress window without reopening the full setup wizard.
- Setup relaunches Sentory after success. On failure, the helper reopens the existing
  executable and records the result in `sentory.log`.

### Updating from older versions

- The new installer waits for an older Sentory process to exit instead of aborting
  immediately, allowing 1.1.3 and 1.1.31 to update directly to 1.1.32.
- Release validation starts from a running app and confirms visible progress, file
  replacement, and automatic restart.

Most Windows PCs should use `Sentory-win-x64-setup.exe`. Use the portable ZIP if you
prefer not to install the app, or an `arm64` package on Windows on ARM. The binaries are
not code-signed, so Windows may show an Unknown Publisher or SmartScreen warning.
