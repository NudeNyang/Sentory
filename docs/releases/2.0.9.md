# Sentory 2.0.9

Sentory와 Discord가 Windows 로그인과 함께 실행될 때 순서가 엇갈리던 부분을 고쳤습니다.

## Discord 시작 순서

Windows 자동 실행과 Discord 감지를 모두 켜면 Sentory가 먼저 시작된 뒤 Discord를 엽니다. Discord에는 감지에 필요한 접근성 실행 옵션을 함께 전달합니다.

`NudeNyang Translator`도 자동 실행으로 등록되어 있다면 Translator 프로세스의 시작까지 확인합니다. Translator를 쓰지 않거나 자동 실행을 꺼 둔 PC에서는 따로 기다리지 않습니다.

대기 시간은 최대 30초입니다. Translator가 늦게 시작되거나 실행에 실패해도 Discord는 계속 열립니다. Sentory 자체가 시작되지 않은 경우에는 보관해 둔 Discord의 원래 시작 명령을 복원한 다음 Discord를 실행합니다.

이 동작은 별도 설정을 추가하지 않습니다. 기존의 Windows 자동 실행과 Discord 감지 설정을 그대로 사용합니다.

Microsoft Store판은 Sentory 자체를 시작할 때 이전과 같이 Windows `StartupTask`를 사용합니다. Discord 시작 순서 조정은 Store 패키지 권한과 함께 적용되며, GitHub 업데이트 기능은 들어가지 않습니다.

## 다운로드

| 사용 환경 | 설치형 | 포터블 |
| --- | --- | --- |
| Intel·AMD Windows PC | `Sentory-win-x64-setup.exe` | `Sentory-win-x64-portable.zip` |
| Windows on ARM PC | `Sentory-win-arm64-setup.exe` | `Sentory-win-arm64-portable.zip` |

2.0.8 GitHub판에서는 앱 안에서 2.0.9 업데이트를 확인할 수 있습니다. 배포 파일에는 아직 코드 서명이 없어 Windows에서 알 수 없는 게시자 또는 SmartScreen 경고가 나올 수 있습니다. 공식 Release에서 받은 파일인지 확인하고, 필요하면 함께 제공되는 `.sha256` 파일과 비교해 주세요.

---

## English

Sentory 2.0.9 coordinates Windows login startup so Sentory launches before Discord. If `NudeNyang Translator` is also registered for startup, Sentory waits for its process before starting Discord with the accessibility argument.

The wait is limited to 30 seconds. Discord still starts if Translator is late or unavailable. If Sentory itself does not start, the managed command restores Discord's original startup registration before launching it. Microsoft Store builds keep using `StartupTask` for Sentory and do not include the GitHub updater.
