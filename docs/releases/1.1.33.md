# Sentory 1.1.33

Sentory 1.1.33에서는 필터 숫자와 Discord 감지 상태를 실제 동작에 맞게
표시하도록 손봤습니다. 트레이 메뉴를 여는 속도도 개선했고, 이미 설치한 버전의
업데이트 안내가 다시 나타날 수 있는 경로를 막았습니다.

## 필터 숫자와 Discord 상태

- Discord와 카카오톡을 함께 선택하면 필터 숫자가 `2`로 표시됩니다. 날짜 조건을
  더하면 해당 조건도 별도로 계산합니다.
- Discord가 준비 중이거나 연결을 복구하는 동안 보관함, 설정과 트레이에서 같은
  상태를 확인할 수 있습니다.
- 새 PC에서 Discord 접근성 대상을 계속 찾지 못하면 재연결 안내로 바뀝니다.
  채널을 옮길 때 생기는 짧은 실패는 기존처럼 자동으로 복구합니다.

## 빠른 트레이 메뉴

트레이 아이콘을 우클릭할 때마다 메뉴를 새로 만들던 동작을 바꿨습니다. 처음 만든
창을 숨겨 두었다가 다시 사용하므로 두 번째부터는 바로 열리고, 첫 메뉴도 앱이
한가한 시점에 미리 준비합니다.

## 한 번만 뜨는 업데이트 안내

다운로드가 끝난 후보를 화면에 표시하기 직전에 현재 버전을 다시 비교합니다.
같거나 낮은 버전이면 안내창과 수동 설치 버튼을 띄우지 않습니다.

## 다운로드

대부분의 Windows PC에서는 `Sentory-win-x64-setup.exe`를 받으면 됩니다. 설치하지
않고 사용하려면 `Sentory-win-x64-portable.zip`을 완전히 푼 뒤 `Sentory.exe`를
실행해 주세요. Windows on ARM 사용자는 이름에 `arm64`가 포함된 파일을 선택해
주세요.

현재 파일에는 코드 서명이 적용되지 않았습니다. Windows에서 알 수 없는 게시자나
SmartScreen 경고가 나타날 수 있습니다. 공식 Release에서 받은 파일인지
확인하고, 필요하면 함께 제공되는 `.sha256` 파일과 대조해 주세요.

이 Release의 실행 파일에 대응하는 소스는 `Sentory-1.1.33-source.zip`과
`v1.1.33` 태그에서 받을 수 있습니다.

## 알려진 제한 사항

- Discord의 `+` 버튼을 이용한 파일 선택 업로드는 아직 감지를 보장하지 않습니다.
  사진은 채팅 입력창에 Ctrl+V로 붙여넣은 뒤 전송해 주세요.
- Discord 또는 카카오톡의 화면 구조가 바뀌면 감지가 잠시 멈출 수 있습니다.
- ARM64 패키지는 실제 Windows on ARM 장치에서 최종 검수가 남아 있습니다.
- 실행 파일과 설치 프로그램에는 코드 서명이 적용되지 않았습니다.

## English

Sentory 1.1.33 fixes the active filter count, makes Discord connection states visible,
reuses the tray menu for faster opening, and suppresses stale update prompts for the
same or an older version.

### Filter count and Discord status

- Selecting Discord and KakaoTalk now shows `2` active filters. A date condition is
  counted separately.
- The library, settings, and tray now show consistent Discord connecting and recovery
  states.
- A prolonged first-time connection failure becomes an actionable reconnect prompt,
  while brief failures during channel changes continue through normal recovery.

### Faster tray menu

Sentory now reuses and preloads its tray menu instead of rebuilding the window on every
right-click.

### No stale update prompt

The app compares the downloaded candidate with its running version immediately before
showing or installing it. Same-version, older, and invalid candidates are ignored.

Most Windows PCs should use `Sentory-win-x64-setup.exe`. Use the portable ZIP if you
prefer not to install the app, or an `arm64` package on Windows on ARM. The binaries are
not code-signed, so Windows may show an Unknown Publisher or SmartScreen warning.
