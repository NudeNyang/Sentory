# Sentory 1.1.1

Sentory 1.1.1은 새로 설치한 환경에서 Windows 자동 실행을 기본으로 켜고,
기존 사용자가 선택한 상태는 그대로 유지하는 업데이트입니다.

## Windows 자동 실행 기본값

- 새로 설치한 Sentory를 처음 정상 실행하면 Windows 자동 실행이 켜집니다.
- 기존 사용자는 현재 시작 프로그램 등록 상태를 그대로 유지합니다. 업데이트
  과정에서 꺼 둔 자동 실행이 다시 켜지지 않습니다.
- 설정 화면이나 트레이 메뉴에서 자동 실행을 바꾸면 선택한 값이 설정 파일과
  Windows 시작 프로그램에 함께 반영됩니다.
- 설치 패키지 자체 점검과 Discord 접근성 워커는 자동 실행 설정을 변경하지
  않습니다.

## 다운로드

대부분의 Windows PC에서는 `Sentory-win-x64-setup.exe`를 받으시면 됩니다.
설치하지 않고 사용하려면 `Sentory-win-x64-portable.zip`을 완전히 푼 뒤
`Sentory.exe`를 실행해 주세요. Windows on ARM 사용자는 이름에 `arm64`가
포함된 파일을 선택해 주세요.

현재 파일에는 코드 서명이 적용되지 않았으므로 Windows에서 알 수 없는 게시자나
SmartScreen 경고가 나타날 수 있습니다. 공식 Release에서 받은 파일인지 확인하고,
필요한 경우 함께 제공되는 `.sha256` 파일로 확인값을 비교해 주세요.

이 Release의 실행 파일에 대응하는 소스는 `Sentory-1.1.1-source.zip`과
`v1.1.1` 태그에서 받을 수 있습니다.

## 알려진 제한 사항

- Discord 또는 카카오톡의 화면 구조가 바뀌면 감지가 일시적으로 동작하지 않을 수
  있습니다.
- 손글씨, 붓글씨, 매우 작은 글자와 복잡한 배치의 문자는 정확하게 인식되지 않을 수
  있습니다.
- ARM64 패키지는 교차 빌드와 실행 파일 구조 검증을 마쳤지만 실제 Windows on ARM
  장치에서의 최종 검수는 남아 있습니다.

## English

Sentory 1.1.1 enables Start with Windows by default for new installations while
preserving the choice made by existing users.

### Start with Windows default

- The first normal launch of a new installation enables Start with Windows.
- Existing users keep their current startup registration. An update does not turn the
  setting back on after it has been disabled.
- Changes made from Sentory settings or the tray menu are stored in both the settings
  file and the Windows startup registration.
- Package verification and the Discord accessibility worker do not modify the startup
  setting.

Most Windows PCs should use `Sentory-win-x64-setup.exe`. Use the portable ZIP if you
prefer not to install the app, or an `arm64` package on Windows on ARM. The binaries
are not code-signed, so Windows may show an Unknown Publisher or SmartScreen warning.

Detection may stop temporarily if Discord or KakaoTalk changes its interface.
Handwriting, calligraphy, extremely small text, and complex layouts may not be
recognized accurately. Final testing of the ARM64 package on physical Windows on ARM
hardware is still pending.
