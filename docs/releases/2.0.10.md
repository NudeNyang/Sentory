# Sentory 2.0.10

NudeNyang Translator와 함께 자동 실행할 때 생기던 Discord 시작 순서 충돌을 정리했습니다. 두 프로그램이 각자 Discord를 다시 열지 않도록 시작 주체를 하나로 맞췄고, 예전 설정도 안전하게 정리합니다.

## NudeNyang Translator와 함께 사용할 때

NudeNyang Translator의 자동 실행이 켜져 있으면 Translator가 Discord를 보안 파이프와 접근성 옵션으로 엽니다. Sentory는 Translator가 연 프로세스를 확인하면 종료하거나 다시 시작하지 않고 그대로 연결합니다. 로그인할 때 Discord가 두 번 열리거나 두 프로그램이 서로 재시작시키는 문제를 막았습니다.

예전 버전에서 등록한 `--remote-debugging-port=9222` 시작 명령이나 PowerShell 대기 명령이 남아 있으면 안전한 일반 시작 명령으로 바꿉니다. 사용자가 직접 바꾼 다른 시작 명령은 덮어쓰지 않습니다.

NudeNyang Translator를 사용하지 않거나 자동 실행을 꺼 두었다면 GitHub판 Sentory가 이전처럼 Discord 접근성 시작을 관리합니다.

## Microsoft Store판

Store판은 Sentory 자체 자동 실행에 Windows `StartupTask`만 씁니다. Discord의 Windows 시작 레지스트리와 Sentory의 기존 백업 레지스트리는 읽거나 쓰지 않습니다. MSIX 매니페스트에도 `unvirtualizedResources` 같은 제한 기능을 넣지 않았습니다.

제품 버전은 2.0.10이고 Partner Center 제출용 MSIX 번들 버전은 2.0.10.0입니다. 번들 하나에 x64와 ARM64 패키지가 함께 들어 있습니다.
