# Sentory 2.0.7

Sentory 2.0.7은 앱을 켰을 때 보관함이 바로 열리던 동작을 바꾸고, 제품 소개 페이지를 네 언어와 모바일 화면에 맞게 다듬은 업데이트입니다.

## 최소화 상태로 시작

이제 Sentory를 실행하면 보관함이 작업표시줄에 최소화된 상태로 시작합니다. 따로 설정할 필요는 없습니다. Windows 시작 프로그램으로 실행할 때도 작업 중인 화면을 가리거나 포커스를 가져오지 않고 감지를 준비합니다.

보관함이 필요하면 작업표시줄의 Sentory를 누르거나 트레이 아이콘을 왼쪽으로 누르면 됩니다. Sentory가 이미 실행 중일 때 프로그램을 다시 실행해도 기존 창이 복원됩니다.

## 네 언어로 볼 수 있는 소개 페이지

제품 소개 페이지에서 한국어, 영어, 일본어, 중국어를 고를 수 있습니다. 처음에는 한국어로 열리고 직접 고른 언어는 다음 방문에도 유지됩니다. 제목과 기능 설명뿐 아니라 다운로드, FAQ, 접근성 문구도 함께 바뀝니다.

지원 메신저 설명은 언어에 따라 실제 사용 환경에 가까운 예시를 보여줍니다. 한국어는 카카오톡, 영어는 WhatsApp, 일본어는 LINE, 중국어는 WeChat을 대표 예시로 사용합니다. 언어 메뉴와 앱 지원 언어 버튼은 마우스와 키보드로 모두 조작할 수 있습니다.

## 실제 화면 중심으로 정리한 소개

사용 흐름에는 Sentory를 실제로 쓰는 영상을 넣었습니다. 화면을 빠르게 지나가면 재생하지 않고, 영상이 충분히 보이는 상태가 잠시 이어질 때만 자동으로 시작합니다. Windows에서 모션 감소를 사용하고 있다면 자동 재생하지 않습니다.

사진 속 글자 검색 기능에는 더미 화면 대신 실제 OCR 검색 결과와 항목 상세 화면을 사용했습니다. 지원 메신저 로고는 각 서비스의 공식 다운로드 페이지로 연결됩니다. 클라우드와 NAS를 이용한 컴퓨터 간 동기화도 소개 페이지에서 확인할 수 있습니다.

Sentory가 별도 서버 없이 Windows PC에 내용을 보관한다는 점과 무료 오픈소스 프로그램이라는 점도 분명하게 적었습니다. 다운로드 버튼은 항상 최신 GitHub Release를 엽니다.

## 모바일 화면과 줄바꿈

휴대폰에서도 메뉴와 버튼을 누르기 쉽도록 터치 영역, 글자 크기와 여백을 조정했습니다. 지원 메신저와 기능 카드, 다운로드, FAQ는 작은 화면에서 지나치게 길어지지 않도록 간격을 줄였습니다.

한국어는 어절 중간이 갈라지지 않게 하고 영어는 단어를 유지합니다. 일본어와 중국어는 문장부호가 줄 앞에 남지 않도록 언어별 줄바꿈 규칙을 나눴습니다.

## 다운로드

| --- | --- | --- |
| Intel·AMD Windows PC | `Sentory-win-x64-setup.exe` | `Sentory-win-x64-portable.zip` |
| Windows on ARM PC | `Sentory-win-arm64-setup.exe` | `Sentory-win-arm64-portable.zip` |

2.0.6 GitHub판은 앱 안에서 2.0.7을 확인하고 내려받을 수 있습니다. Microsoft Store판은 Store에서 업데이트하며 앱 안의 GitHub 업데이트 메뉴와 확인 경로는 포함하지 않습니다.

현재 GitHub Release의 실행 파일과 설치 프로그램은 코드 서명을 받지 않았습니다. Windows에서 알 수 없는 게시자 또는 SmartScreen 경고가 나타날 수 있으니 공식 Release에서 받은 파일인지 확인하고, 필요하면 함께 제공되는 `.sha256` 파일과 비교해 주세요.

## English

Sentory 2.0.7 now starts with the library window minimized by default, without taking focus from your current work. Use the taskbar, left-click the tray icon, or launch Sentory again to restore the existing window.

The product page is now available in Korean, English, Japanese, and Chinese. It remembers the selected language and localizes the main content, downloads, FAQ, accessibility labels, and messenger examples.

The site now uses a real Sentory walkthrough video and actual OCR search and detail screens. Mobile spacing, touch targets, typography, and language-specific line breaking have also been improved.

Microsoft Store builds use Store updates and do not expose the in-app GitHub update path. The GitHub Release includes x64 and ARM64 installers and portable packages. These files are not code-signed, so Windows may show an Unknown Publisher or SmartScreen warning.
