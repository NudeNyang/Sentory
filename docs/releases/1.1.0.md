# Sentory 1.1.0

Sentory 1.1.0은 사진 속 글자를 로컬에서 읽어 제목과 검색에 활용하고, 메신저에서
저장한 자료를 더 안정적으로 다시 찾고 다룰 수 있도록 정리한 업데이트입니다.

## 사진을 글자로 찾을 수 있습니다

- 한국어·영어·일본어·중국어를 지원하는 PP-OCRv5 모바일 모델을 앱에
  포함했습니다. 사진 속에서 인식한 글자는 보관함 검색에 바로 사용할 수 있습니다.
- 의미 있는 원본 파일명이나 이미지 메타데이터 제목은 그대로 살립니다. 해시값,
  단순 일련번호, 일반적인 촬영 파일명은 OCR 결과와 비교해 더 알아보기 쉬운 쪽을
  제목으로 선택합니다.
- 일본어 세로쓰기 후보를 따로 검사하고, 너무 작은 글자나 신뢰도가 낮은 조각은
  제목에서 제외합니다.
- OCR은 사진의 SHA-256을 기준으로 한 번만 처리합니다. 한 번에 한 작업씩
  백그라운드에서 실행하고, 작업이 끝나면 모델 메모리를 해제합니다.

OCR은 Windows PC 안에서만 처리합니다. 원본 사진이나 인식된 글자를 OCR 용도로
외부 서버에 보내지 않습니다.

## 저장과 상세 화면을 다듬었습니다

- 같은 전송에서 사진을 한 장씩 연달아 붙여넣어도 하나의 묶음으로 저장됩니다.
- 사진·링크 상세창을 최대화하면 원본 비율을 유지한 채 미리보기와 내용 영역이
  함께 커집니다.
- 제목과 세부 내용을 마우스로 선택해 복사할 수 있습니다. 글자에서 조금 떨어진
  여백에서 드래그를 시작해도 한 항목만 정확하게 선택됩니다.
- 글자를 드래그한 뒤 마우스를 놓을 때 사진이 열리거나, 보조 창을 닫으면서 메인
  창까지 숨겨지던 문제를 수정했습니다.
- 상세창과 설정창은 다른 앱으로 전환해도 그대로 유지됩니다. Sentory 메인 화면의
  배경을 직접 클릭했을 때만 닫힙니다.

## 화면 반응을 가볍게 정리했습니다

- 전체·링크·사진·즐겨찾기 필터와 선택 모드 전환에서 불필요한 화면 갱신을 줄였습니다.
- 설정 선택창을 한 덩어리로 이어진 패널처럼 보이도록 정리하고, 라이트·다크 테마를
  바꿀 때 남던 잔상을 줄였습니다.
- 모든 보조 창에 같은 얇은 자동 숨김 스크롤 표시기를 적용했습니다.
- 앱을 실행하면 보관함과 작업 표시줄 항목이 함께 나타납니다. 앱 아이콘도 Windows가
  허용하는 범위 안에서 더 또렷하게 보이도록 조정했습니다.
- Discord 감지 상태는 복구 중이거나 Discord 재시작이 필요한 경우에만 표시됩니다.

## 다운로드

대부분의 Windows PC에서는 `Sentory-win-x64-setup.exe`를 받으시면 됩니다.
설치하지 않고 사용하려면 `Sentory-win-x64-portable.zip`을 완전히 푼 뒤
`Sentory.exe`를 실행해 주세요. Windows on ARM 사용자는 이름에 `arm64`가
포함된 파일을 선택해 주세요.

로컬 OCR 모델이 포함되어 설치형과 포터블 패키지 용량이 이전 버전보다 늘었습니다.
현재 파일에는 코드 서명이 적용되지 않았으므로 Windows에서 알 수 없는 게시자나
SmartScreen 경고가 나타날 수 있습니다. 공식 Release에서 받은 파일인지 확인하고,
필요한 경우 함께 제공되는 `.sha256` 파일로 확인값을 비교해 주세요.

이 Release의 실행 파일에 대응하는 소스는 `Sentory-1.1.0-source.zip`과
`v1.1.0` 태그에서 받을 수 있습니다.

## 알려진 제한 사항

- 손글씨, 붓글씨, 매우 작은 글자와 복잡한 배치의 문자는 정확하게 인식되지 않을 수
  있습니다.
- Discord 또는 카카오톡의 화면 구조가 바뀌면 감지가 일시적으로 동작하지 않을 수
  있습니다.
- ARM64 패키지는 교차 빌드와 실행 파일 구조 검증을 마쳤지만 실제 Windows on ARM
  장치에서의 최종 검수는 남아 있습니다.

## English

Sentory 1.1.0 adds fully local image OCR and improves the way saved images are named,
searched, grouped, and reviewed.

### Image OCR and search

- Added bundled PP-OCRv5 mobile models for Korean, English, Japanese, and Chinese.
  Recognized image text is now searchable in the library.
- Preserved meaningful original filenames and image metadata titles. Hash-like names,
  simple sequence numbers, and generic camera filenames are compared with OCR text so
  the more useful title is displayed.
- Added a separate pass for likely vertical Japanese text and filtered tiny or
  low-confidence fragments from generated titles.
- Cached OCR by image SHA-256, processed one background job at a time, and released
  model memory after the queue became idle.

Image OCR runs entirely on the local Windows PC. Sentory does not upload source images
or recognized text to an OCR service.

### Saving and detail windows

- Fixed separately pasted images from the same send so they remain in one collection.
- Made image and link detail windows scale their preview and content layout when
  maximized.
- Added selectable titles and details with a more forgiving drag area while keeping
  selection limited to one field.
- Prevented an image from opening at the end of a text drag and prevented auxiliary
  windows from hiding the main library window when they close.
- Kept detail and settings windows open while switching to another app. They close
  automatically only after the Sentory background is clicked.

### Responsiveness and interface

- Reduced unnecessary redraws when switching the main filters or selection mode.
- Unified the settings selection panel and removed the lingering transition effect
  when switching between light and dark themes.
- Applied the same slim auto-hiding scroll indicator to auxiliary windows.
- Ensured that the library and taskbar entry appear together on startup and adjusted
  the app icon for clearer display.
- Limited Discord detection notices to recovery and restart-required states.

Most Windows PCs should use `Sentory-win-x64-setup.exe`. Use the portable ZIP if you
prefer not to install the app, or an `arm64` package on Windows on ARM. Bundled local
OCR models make the packages larger than the previous release. The binaries are not
code-signed, so Windows may show an Unknown Publisher or SmartScreen warning.

Handwriting, calligraphy, extremely small text, and complex layouts may not be
recognized accurately. Detection may also stop temporarily if Discord or KakaoTalk
changes its interface. Final testing of the ARM64 package on physical Windows on ARM
hardware is still pending.
