지원 메신저

보내고 잊어버려도,
필요할 때 다시 찾을 수 있게.

대화방을 거슬러 올라가는 대신 제목, URL, 도메인과 사진 속 글자로 보관함을 검색하세요.

  1. 붙여넣고 보내기 평소처럼 지원 메신저를 사용합니다.
  2. 자동으로 모으기 링크와 사진이 카드 또는 묶음으로 저장됩니다.
  3. 검색하고 다시 쓰기 복사하거나 원본을 열어 바로 이어서 사용합니다.

보관함을 만드는 기준부터 다릅니다.

모든 클립보드 기록을 쌓지 않고, 지원 메신저에서 필요한 순간만 골라 기억합니다.

Private by design

보관함은내 컴퓨터에 남습니다.

Sentory는 광고 추적기와 분석 도구를 넣지 않습니다. 사진 OCR도 Windows에서 로컬로 처리합니다.

  • 로컬 SQLite와 이미지 폴더에 저장
  • 사진 OCR을 기기에서 처리
  • 메신저별 감지를 따로 설정
  • 선택한 클라우드 또는 NAS에 직접 동기화

자주 묻는 질문

모든 클립보드 내용을 저장하나요?

아닙니다. 지원 메신저의 채팅 입력 영역을 확인한 뒤 정해진 조건에 맞는 링크와 사진만 저장합니다.

메시지를 보내지 않아도 저장되나요?

Discord, Slack, WhatsApp, Telegram, LINE, WeChat은 실제 전송 뒤 저장합니다. 카카오톡은 채팅창에 붙여넣거나 탐색기에서 드롭한 시점에 저장합니다.

데이터는 어디에 저장되나요?

기본 보관함은 %LOCALAPPDATA%\Sentory에 저장됩니다. Sentory 운영 서버로 보관 데이터를 보내지 않습니다.

컴퓨터끼리 동기화할 수 있나요?

직접 고른 클라우드 폴더나 NAS WebDAV를 연결하면 Windows 컴퓨터 사이에서 사진, 링크와 사용 상태를 맞출 수 있습니다.

macOS와 Linux에서도 사용할 수 있나요?

현재 정식 배포는 Windows 10과 11의 x64, ARM64만 지원합니다. macOS와 Linux 배포 일정은 아직 정해지지 않았습니다.
