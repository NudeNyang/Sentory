Sentory 무설치판 사용 방법
==========================

1. 압축 파일을 원하는 폴더에 완전히 풀어 주세요.
2. Sentory.App.exe를 실행해 주세요.
3. Windows 작업 표시줄 알림 영역의 새 모양 Sentory 아이콘을 확인해 주세요.
4. 아이콘을 더블클릭하면 보관함이 열립니다.
5. 아이콘을 우클릭하면 설정, 감지 일시정지, 종료 기능을 사용할 수 있습니다.

데이터 저장 위치
----------------

사진, 링크, 설정과 진단 로그는 실행 파일 옆이 아니라 아래 사용자 폴더에 저장됩니다.

%LOCALAPPDATA%\Sentory

새 버전으로 바꿀 때는 Sentory를 종료한 뒤 기존 실행 폴더의 파일을 새 파일로 교체해 주세요.
실행 폴더를 삭제하거나 옮겨도 위 데이터 폴더는 그대로 유지됩니다.

주의 사항
---------

- 현재 Windows 10/11 64비트용입니다.
- Discord와 카카오톡의 화면 구조가 바뀌면 감지가 일시적으로 동작하지 않을 수 있습니다.
- Discord는 실제 전송이 확인된 링크와 사진만 저장합니다.
- 카카오톡은 채팅 입력창에 붙여넣은 링크와 사진을 전송 전에도 즉시 저장합니다.
- 다른 앱이나 카카오톡 검색창의 붙여넣기는 저장하지 않습니다.
- 프로그램을 완전히 종료하려면 알림 영역 아이콘을 우클릭한 뒤 종료를 선택해 주세요.
