Sentory 2.0.9 사용 방법
========================

Sentory는 이야기 속, 흩어진 순간들을 한 곳에 모아 보는 Windows 프로그램입니다.

지원 환경
---------

- Windows 10/11 64비트
- Intel·AMD x64 PC 또는 Windows on ARM PC

설치형 사용 방법
----------------

1. Intel·AMD PC에서는 Sentory-win-x64-setup.exe를 실행해 주세요.
   Windows on ARM에서는 Sentory-win-arm64-setup.exe를 실행해 주세요.
2. 설치 화면에서 라이선스를 확인하고 설치해 주세요.
3. 설치가 끝나면 시작 메뉴의 Sentory를 실행해 주세요.

현재 배포 파일은 코드 서명되지 않았습니다. Windows에서 게시자를 확인할
수 없다는 안내가 나타날 수 있으므로 공식 GitHub Release의 파일 이름과
SHA-256 확인값을 확인한 뒤 실행해 주세요.

설치형은 현재 사용자 계정의 아래 폴더에 설치되며 관리자 권한을 요구하지 않습니다.

%LOCALAPPDATA%\Programs\Sentory

포터블 사용 방법
----------------

1. PC에 맞는 portable ZIP을 원하는 폴더에 완전히 풀어 주세요.
2. 압축을 푼 폴더의 Sentory.exe를 실행해 주세요.
3. ZIP 안에서 직접 실행하지 마세요.

실행과 종료
-----------

- Sentory를 실행하면 보관함 창과 작업 표시줄 아이콘이 바로 나타납니다.
- 새로 설치한 환경에서는 Windows 자동 실행이 기본으로 켜집니다.
- 자동 실행은 설정 화면이나 알림 영역 메뉴에서 끄거나 다시 켤 수 있습니다.
- 창을 닫아도 Sentory는 알림 영역에서 계속 실행됩니다.
- 알림 영역의 새 모양 아이콘을 더블클릭하면 보관함이 열립니다.
- 완전히 종료하려면 아이콘을 우클릭한 뒤 종료를 선택해 주세요.

데이터 저장 위치
----------------

사진, 링크, 설정과 진단 로그는 프로그램 폴더가 아니라 아래에 저장됩니다.

%LOCALAPPDATA%\Sentory

프로그램을 제거하거나 새 버전으로 교체해도 이 데이터는 자동 삭제되지 않습니다.
모든 데이터를 지우려면 Sentory를 완전히 종료한 뒤 위 폴더를 직접 삭제해 주세요.

업데이트
--------

Sentory는 실행 뒤와 6시간마다 GitHub Releases에서 새 버전을 확인합니다.
새 버전이 있으면 PC와 설치 방식에 맞는 파일을 내려받아 SHA-256을 확인합니다.
설정에 설치 버튼이 나타난 뒤 누르면 Sentory를 종료하고 업데이트한 다음 자동으로
다시 실행합니다. 지금 확인 버튼을 누르면 대기하지 않고 바로 확인합니다. 보관
데이터는 프로그램과 다른 폴더에 있어 새 버전을 설치해도 그대로 유지됩니다.

사진 제목과 검색
----------------

- 사진 속 한국어·영어·일본어·중국어는 로컬 OCR로 인식해 검색에 사용합니다.
- 의미 있는 원본 파일명이나 이미지 제목은 유지하고, 해시값이나 일반적인 촬영
  파일명은 OCR 결과와 비교해 더 알아보기 쉬운 제목을 표시합니다.
- OCR은 PC 안에서만 처리하며 원본 사진이나 인식된 글자를 외부 서버에 보내지 않습니다.
- 보관함에서 사진을 열면 화면 제목과 같은 파일명으로 Windows 사진 앱에 표시합니다.
- 손글씨, 붓글씨, 매우 작은 글자와 복잡한 배치는 정확하게 인식되지 않을 수 있습니다.

감지 범위와 주의 사항
---------------------

- 처음 실행하면 모든 메신저 감지가 꺼진 상태로 표시됩니다. 사용할 메신저만
  고른 뒤 선택을 마쳐 주세요. 기존 사용자의 설정은 그대로 유지됩니다.
- Discord는 실제 전송이 확인된 링크와 사진만 저장합니다.
- Discord 감지를 처음 켤 때 자동 재시작 동의를 받습니다. 작성 중인 메시지가
  취소되거나 통화가 종료될 수 있으니 안내를 확인한 뒤 선택해 주세요.
- 새로 실행한 Discord에 접근성 옵션이 없으면 메인 창을 찾는 즉시 15초
  재시작 안내를 표시합니다. 안내창에서 취소하거나 바로 재시작할 수 있습니다.
- Slack, WhatsApp, Telegram, LINE과 WeChat은 지원 채팅에 붙여넣거나
  탐색기에서 드롭한 링크·사진을 실제로 전송한 뒤 저장합니다.
- 카카오톡은 지원 채팅 입력창에 붙여넣은 링크와 사진을 전송 전에도 저장합니다.
- 다른 앱이나 카카오톡 검색창의 붙여넣기는 저장하지 않습니다.
- 메신저의 + 버튼으로 파일 선택창을 여는 업로드는 감지를 보장하지 않습니다.
  사진은 채팅 입력창에 붙여넣거나 탐색기에서 드롭한 뒤 전송해 주세요.
- 지원 메신저의 화면 구조가 바뀌면 감지가 일시적으로 동작하지 않을 수 있습니다.
- ARM64 패키지는 ARM64 Windows 가상 환경에서 실행 자체 점검을 마쳤습니다.
  메신저를 설치한 실제 Windows on ARM 장치에서의 통합 검수는 남아 있습니다.

컴퓨터 간 동기화
----------------

설정에서 컴퓨터 간 동기화를 켜면 OneDrive, Google Drive, Dropbox, MEGA,
직접 고른 폴더나 NAS WebDAV 공유 폴더를 사용할 수 있습니다. 사진은 일반 이미지
파일, 링크는 읽을 수 있는 TXT로 저장되며 같은 저장소를 연결한 Windows
컴퓨터끼리 추가·삭제·즐겨찾기·복사 횟수를 맞춥니다. Sentory가 운영하는 서버는
거치지 않습니다.
