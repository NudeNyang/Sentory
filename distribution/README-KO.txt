Sentory 1.0.0 사용 방법
========================

Sentory는 붙여넣기한 사진과 링크를 한 곳에서 확인하는 Windows 프로그램입니다.

지원 환경
---------

- Windows 10/11 64비트
- 일반적인 Intel·AMD PC: win-x64 파일
- Windows on ARM PC: win-arm64 파일

설치형 사용 방법
----------------

1. PC에 맞는 Sentory-win-x64-setup.exe 또는 Sentory-win-arm64-setup.exe를 실행해 주세요.
2. 설치 화면에서 라이선스를 확인하고 설치해 주세요.
3. 설치가 끝나면 시작 메뉴의 Sentory를 실행해 주세요.

현재 배포 파일은 코드 서명되지 않았습니다. Windows에서 게시자를 확인할
수 없다는 안내가 나타날 수 있으므로 공식 GitHub Release의 파일 이름과
SHA-256 확인값을 확인한 뒤 실행해 주세요.

설치형은 현재 사용자 계정의 아래 폴더에 설치되며 관리자 권한을 요구하지 않습니다.

%LOCALAPPDATA%\Programs\Sentory

포터블 사용 방법
----------------

1. PC에 맞는 portable ZIP을 원하는 폴더에 완전히 풀어 주세요.
2. 압축을 푼 폴더의 Sentory.exe를 실행해 주세요.
3. ZIP 안에서 직접 실행하지 마세요.

실행과 종료
-----------

- Sentory를 실행하면 보관함 창과 작업 표시줄 아이콘이 바로 나타납니다.
- 창을 닫아도 Sentory는 알림 영역에서 계속 실행됩니다.
- 알림 영역의 새 모양 아이콘을 더블클릭하면 보관함이 열립니다.
- 완전히 종료하려면 아이콘을 우클릭한 뒤 종료를 선택해 주세요.

데이터 저장 위치
----------------

사진, 링크, 설정과 진단 로그는 프로그램 폴더가 아니라 아래에 저장됩니다.

%LOCALAPPDATA%\Sentory

프로그램을 제거하거나 새 버전으로 교체해도 이 데이터는 자동 삭제되지 않습니다.
모든 데이터를 지우려면 Sentory를 완전히 종료한 뒤 위 폴더를 직접 삭제해 주세요.

업데이트
--------

Sentory는 실행 후 GitHub Releases에서 새 버전을 자동으로 확인합니다. 새
버전이 있으면 설치 여부를 묻고, 승인하면 PC 아키텍처와 설치 방식에 맞는
파일을 내려받아 SHA-256을 확인한 뒤 업데이트합니다. 보관 데이터는 별도
폴더에 있으므로 업데이트 후에도 그대로 유지됩니다.

감지 범위와 주의 사항
---------------------

- Discord는 실제 전송이 확인된 링크와 사진만 저장합니다.
- 카카오톡은 지원 채팅 입력창에 붙여넣은 링크와 사진을 전송 전에도 저장합니다.
- 다른 앱이나 카카오톡 검색창의 붙여넣기는 저장하지 않습니다.
- Discord와 카카오톡의 화면 구조가 바뀌면 감지가 일시적으로 동작하지 않을 수 있습니다.
- ARM64 버전은 ARM64 Windows 장치에서 추가 실사용 검수가 필요합니다.
