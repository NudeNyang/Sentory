# Sentory

[한국어](./README.md) | [English](./README.en.md)

> 붙여넣기한 사진과 링크를 한 곳에서

Sentory는 메신저에서 다룬 링크와 사진을 따로 모아 관리하는 앱입니다. 저장된 항목을
검색하고, 원본을 열거나 필요할 때 다시 복사할 수 있습니다.

현재 공개 베타에서는 Discord와 카카오톡을 지원합니다. 시스템 전체를 기록하는
클립보드 관리자가 아니라, 지원하는 메신저의 채팅 입력 영역을 확인하고 정해진
조건을 충족한 링크와 사진만 저장합니다. 지원하는 메신저는 앞으로 늘려갈 예정입니다.

## 현재 지원하는 메신저

| 메신저 | 저장 시점 | 저장하지 않는 경우 |
| --- | --- | --- |
| Discord | 붙여넣은 링크나 사진이 실제로 전송된 뒤 | 붙여넣기만 한 경우, `Shift+Enter`, 첨부 취소 |
| 카카오톡 | 개별 채팅 입력창에 링크나 사진을 붙여넣는 순간 | 직접 타이핑한 주소, 검색창 입력, 채팅창 밖의 입력 |

다른 앱에서 복사하거나 붙여넣은 내용에는 반응하지 않습니다. Discord와 카카오톡의
창과 입력 영역을 먼저 확인하기 때문에 평소 작업을 클립보드 기록으로 쌓지 않습니다.

## 주요 기능

- 링크와 사진을 카드로 한눈에 확인
- 제목, URL, 도메인 검색
- 메신저·종류·기간 필터와 다양한 정렬 방식
- 즐겨찾기와 즐겨찾기를 보존하는 자동 정리
- 카드에서 바로 원본 열기 또는 복사
- 실시간 드래그 선택과 여러 항목 일괄 삭제
- 링크의 페이지 제목, 사이트 아이콘, 대표 이미지와 짧은 설명 표시
- 라이트·다크 테마 및 한국어·영어·일본어·중국어 UI
- 현재 Windows 버전의 시작 시 자동 실행과 트레이 빠른 설정

## 데이터 저장

현재 Windows 버전의 사진, 링크, 설정과 사용 기록은 아래 로컬 폴더에 저장됩니다.

```text
%LOCALAPPDATA%\Sentory
```

Sentory가 운영하는 서버로 보관 데이터를 전송하지 않으며 별도의 분석·추적 기능도
두지 않았습니다. 링크 미리보기를 만들 때는 해당 웹사이트에 일반적인 네트워크 요청을
보낼 수 있습니다. 자세한 내용은 [개인정보 및 로컬 데이터 안내](./PRIVACY.md)에서
확인할 수 있습니다.

## 다운로드

현재 배포 후보 버전은 **0.9.0-beta**입니다. 이번 버전은 Windows 10/11 64비트용으로
제공됩니다. [Releases](../../releases)에서 PC에 맞는 파일을 내려받으시면 됩니다.
macOS와 Linux 버전도 추가할 예정이지만 아직 배포 파일은 제공하지 않습니다.

| 사용 환경 | 설치형 | 포터블 |
| --- | --- | --- |
| 일반적인 Intel·AMD Windows PC | `Sentory-win-x64-setup.exe` | `Sentory-win-x64-portable.zip` |
| Windows on ARM PC | `Sentory-win-arm64-setup.exe` | `Sentory-win-arm64-portable.zip` |

대부분의 PC에서는 x64 설치형을 선택하시면 됩니다. 설치 없이 사용하려면 포터블 ZIP을
푼 뒤 `Sentory.exe`를 실행하세요. 설치형과 포터블 모두 .NET을 따로 설치할 필요가
없습니다.

현재 배포 파일에는 코드 서명이 적용되지 않았습니다. Windows에서 알 수 없는 게시자
또는 SmartScreen 경고가 표시될 수 있으므로 이 저장소의 공식 Release에서 받은
파일인지 확인해 주세요. 함께 제공되는 `.sha256` 파일로 내려받은 파일의
SHA-256도 비교할 수 있습니다.

## 처음 사용하기

1. Sentory를 실행하세요. 보관함과 작업 표시줄에 앱이 바로 나타납니다.
2. 카카오톡 개별 채팅창에 링크나 사진을 붙여넣거나, Discord에서 붙여넣은 뒤 전송하세요.
3. Sentory 보관함에서 저장된 카드를 열거나 다시 복사하세요.

Discord 감지를 처음 준비할 때는 Discord가 접근성 모드로 다시 시작될 수 있습니다.
Sentory 설정과 보관함에서 감지 상태를 확인하고 필요할 때 다시 연결할 수 있습니다.

## 베타 안내

Sentory는 현재 Windows용 공개 베타 단계입니다. Discord나 카카오톡의 화면 구조가
바뀌면 감지가 일시적으로 동작하지 않을 수 있습니다. 지원 메신저를 추가하고 macOS와
Linux로 지원 범위를 넓힐 예정이며, 구체적인 배포 일정은 아직 정하지 않았습니다.
ARM64 패키지는 교차 빌드와 실행 파일 구조 검증을 마쳤지만 실제 Windows on ARM
장치에서의 최종 검수가 남아 있습니다. 이 버전은 인앱 자동 업데이트를 제공하지
않으므로 새 Release를 직접 내려받아 업데이트해야 합니다.

문제를 발견했다면 개인정보가 담긴 원본 사진이나 대화 내용 대신 Sentory 버전,
Windows 버전, 사용한 메신저와 재현 순서를 알려주시면 됩니다. 자세한 내용은
[지원 정책](./SUPPORT.md)을 참고해 주세요.
